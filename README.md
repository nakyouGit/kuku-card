# くくの カードゲーム

九九のカードゲームを、コンピューターと対戦するウェブゲーム。サーバー不要で、GitHub Pages で公開する。

## 遊び方
- 大きさくらべ: 2枚のうち答えが大きい方（同じなら「おなじ」）を早くタッチ。取った方が2枚もらえる。
- カードとり1: 数が出たら、答えがその数になるカードを早取り。
- カードとり2: 式が出たら、答えが同じになる別の式のカードを早取り（3×4 なら 2×6・4×3。2〜5の段の式だけを出す）。
- お手つきは、その問題だけお休み。15秒だれも取れなければ答えを見せて次へ。
- 終わったら、自分で取れなかった問題を「もう いちど たしかめよう」に並べる。

## 先生が止める（管理者ページ）
- `admin.html` で、先生がカードゲームを全員いっせいに止める・再開できる。止める時に、子どもへ見せる一言も付けられる。
- 子どもの画面は20秒ごとに状態を確かめ、止まっていれば遊びの途中でも「おやすみ」の画面になる。再開すると設定の画面に戻る（途中のゲームは続きからにはならない）。
- 窓口は九九クエストのガス（`js/config.js` の `STOP_API_URL`）。管理者のIDとパスワードも九九クエストと同じで、パスワードはこのリポジトリのどこにも書かない。
- 通信できない時は、止めずに遊べる（回線の不調で授業中の全員が固まらないように）。
- ガス側の変更は alice-gas の `projects/九九クエスト/src/Code.gs`（`cardStatus`・`setCard`）。

## 設定
- 使う段（2〜5の段、複数可。扱う段は `js/config.js` の ALL_DANS で広げられる）、コンピューターの強さ（よわい・ふつう・つよい）、問題の数（5・10・15）。
- 設定は端末に覚える（localStorage）。数値の調整は `js/config.js` だけで行う。

## 構成
| ファイル | 役割 |
| --- | --- |
| `js/config.js` | 設定値（強さ・時間・枚数） |
| `js/deck.js` | カードの組、山札、問題の選び方、判定 |
| `js/cpu.js` | コンピューターの手の決め方 |
| `js/race.js` | 1問ぶんの早取り勝負（お手つき・時間切れ） |
| `js/mode-take.js` / `js/mode-compare.js` | 各モードの進行 |
| `js/ui.js` | 表示だけ |
| `js/settings.js` | 設定画面と保存 |
| `js/main.js` | 画面の切り替え |
| `js/remote.js` | ガスの窓口との通信 |
| `js/stop-watch.js` | 止まっているかの見張り |
| `js/admin.js` / `admin.html` | 管理者ページ |

## 試験

```
npm test
```
