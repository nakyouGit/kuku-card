# くくの カードゲーム

九九のカードゲームを、コンピューターと対戦するウェブゲーム。サーバー不要で、GitHub Pages で公開する。

## 遊び方
- 大きさくらべ: 2枚のうち答えが大きい方（同じなら「おなじ」）を早くタッチ。取った方が2枚もらえる。
- カードとり1: 数が出たら、答えがその数になるカードを早取り。
- カードとり2: 式が出たら、答えが同じになる別の式のカードを早取り（3×4 なら 2×6・4×3。選んだ段の式だけを出す。段は2つ以上選ぶ）。
- お手つきは、その問題だけお休み。15秒だれも取れなければ答えを見せて次へ。
- 終わったら、自分で取れなかった問題を「もう いちど たしかめよう」に並べる。

## 先生が止める（管理者ページ）
- `admin.html` で、先生がカードゲームと九九けんていを、別々に全員いっせいに止める・再開できる。止める時に、子どもへ見せる一言も付けられる。
- 操作名は `js/config.js` の `STOP_TARGETS`（カードゲームは `cardStatus`・`setCard`、九九けんていは `kenteiStatus`・`setKentei`）。九九けんていの見張りは `kentei/game-stop.js`。
- ガス側に `kenteiStatus`・`setKentei` が入るまでは、九九けんていは止まらずに遊べ、管理者ページの九九けんていの欄は「状態が読み取れません」と出る。
- 子どもの画面は20秒ごとに状態を確かめ、止まっていれば遊びの途中でも「おやすみ」の画面になる。再開すると設定の画面に戻る（途中のゲームは続きからにはならない）。
- 窓口は九九クエストのガス（`js/config.js` の `STOP_API_URL`）。管理者のIDとパスワードも九九クエストと同じで、パスワードはこのリポジトリのどこにも書かない。
- 通信できない時は、止めずに遊べる（回線の不調で授業中の全員が固まらないように）。
- ガス側の変更は alice-gas の `projects/九九クエスト/src/Code.gs`（`cardStatus`・`setCard`）。

## 設定
- 使う段（1〜9の段から自由に選ぶ。はじめは2〜5の段。`js/config.js` の DEFAULT_DANS で変えられる）、コンピューターの強さ（よわい・ふつう・つよい）、問題の数（5・10・15）。
- 設定は端末に覚える（localStorage）。数値の調整は `js/config.js` だけで行う。

## 九九けんてい（フラッシュ）
- `kentei/index.html` は、児童が自分で練習する九九けんてい。段（1〜9）と、じゅんばんどおり・ぎゃく・ランダムを選ぶと、式がフラッシュで出る（はやさは 1びょう・2びょう・3びょう・たつじん（0.7びょう）・ウルトラたつじん（0.4びょう）から選ぶ。カウントダウンは はじめだけ）。子どもは声に出して読む（判定はしない）。終わると、9問の式・答え・読み方で こたえあわせ ができる。
- 「よみかたも だす」にすると、式の下に読み方も出る。選べるはやさは `kentei/game-config.js` の SPEEDS。
- 先生が止めると「おやすみ」の画面になる（20秒ごとと、スタートの時に確かめる。見張りは `kentei/game-stop.js`）。
- 2026-11-19: はじめは音声入力で読み方を ○・× 判定する形で作ったが、iPad の Safari で音声入力が反応しなかったため、判定をやめてフラッシュにした。音声の判定の部品（`kuku-judge.js`・`kuku-reading-judge.js`・`speech-session.js`・`sw.js`・`vendor/kuromoji/`）は、マイクテスト（`kentei/mic-test.html`）でだけ使っている。

| ファイル | 役割 |
| --- | --- |
| `kentei/kuku-readings.js` | 81問の読み方 |
| `kentei/game-config.js` | 設定値（選べるはやさなど） |
| `kentei/game-questions.js` | 問題の並び |
| `kentei/game-main.js` / `kentei/game.css` / `kentei/index.html` | 画面と進行 |
| `kentei/game-stop.js` | 先生が止めたかの見張り |
| `kentei/mic-test.html` ほか | 音声入力のマイクテスト（ゲームでは使わない） |

試験の一部（読み方の判定）は `npm install` で kuromoji を入れてから `npm test`。
