# くくの カードゲーム

九九のカードゲームを、コンピューターと対戦するウェブゲーム。サーバー不要で、GitHub Pages で公開する。

## 遊び方
- 大きさくらべ: 2枚のうち答えが大きい方（同じなら「おなじ」）を早くタッチ。取った方が2枚もらえる。
- カードとり1: 数が出たら、答えがその数になるカードを早取り。
- カードとり2: 式が出たら、答えが同じになる別の式のカードを早取り（3×4 なら 2×6・4×3。選んだ段の式だけを出す。段は2つ以上選ぶ）。
- お手つきは、その問題だけお休み。15秒だれも取れなければ答えを見せて次へ。
- 終わったら、自分で取れなかった問題を「もう いちど たしかめよう」に並べる。

## 先生が止める（管理者ページ）
- `admin.html` で、先生がカードゲームを全員いっせいに止める・再開できる。止める時に、子どもへ見せる一言も付けられる。
- 子どもの画面は20秒ごとに状態を確かめ、止まっていれば遊びの途中でも「おやすみ」の画面になる。再開すると設定の画面に戻る（途中のゲームは続きからにはならない）。
- 窓口は九九クエストのガス（`js/config.js` の `STOP_API_URL`）。管理者のIDとパスワードも九九クエストと同じで、パスワードはこのリポジトリのどこにも書かない。
- 通信できない時は、止めずに遊べる（回線の不調で授業中の全員が固まらないように）。
- ガス側の変更は alice-gas の `projects/九九クエスト/src/Code.gs`（`cardStatus`・`setCard`）。

## 設定
- 使う段（1〜9の段から自由に選ぶ。はじめは2〜5の段。`js/config.js` の DEFAULT_DANS で変えられる）、コンピューターの強さ（よわい・ふつう・つよい）、問題の数（5・10・15）。
- 設定は端末に覚える（localStorage）。数値の調整は `js/config.js` だけで行う。

## 九九検定（作成中）
- `kentei/` に、音声入力で九九の読み方を判定する九九検定ゲームを作っている。今はマイクテスト（`kentei/mic-test.html`）だけ。
- iPad の Safari で開く（ホーム画面のアイコンからは開かない）。
- 1秒の判定は「音の検出（speechstart）」の時刻で測る。マイクは毎問カウントダウンの間に開き直す。
- 児童が自分で練習するためのもの。読み方の判定は ○ か ×。音声認識の結果を辞書（kuromoji）で読みがなに直し、よくある読み違い（なな・きゅう・よん・はちはち など）の方が近い時、答えの数がちがう時、正しい読みから遠い（別の式を言った）時だけ × にする。聞き取りが多少あいまいでも、明確な読み違いがなければ ○。線引きは `kentei/kuku-reading-judge.js` の SETTINGS。
- 辞書（約18MB、`kentei/vendor/kuromoji/`、Apache License 2.0）は `kentei/sw.js` で端末に残し、2回目からは通信しない。

| ファイル | 役割 |
| --- | --- |
| `kentei/kuku-readings.js` | 81問の読み方 |
| `kentei/kuku-judge.js` | 答えの数の判定 |
| `kentei/kuku-reading-judge.js` | 読み方の判定（○・×） |
| `kentei/speech-session.js` | 音声認識の包み（自動で聞き直す） |
| `kentei/sw.js` | 辞書を端末に残す |
| `kentei/mic-test.html` | マイクテスト |

試験の一部（読み方の判定）は `npm install` で kuromoji を入れてから `npm test`。
